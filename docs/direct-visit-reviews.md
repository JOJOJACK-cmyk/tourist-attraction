# 직접 방문 후기

## 이용 흐름

홈 종합 후기의 **직접 방문 후기 작성** 또는 주요 메뉴 **방문 후기**에서 `/visit-reviews`로 이동합니다. 기존 회원 계정으로 로그인하거나 해당 화면에서 가입·로그인할 수 있습니다.

관광지·방문일·제목·직접 경험 확인은 필수입니다. 만족한 점이나 아쉬운 점 중 한 항목은 5자 이상 입력합니다. 구매 품목·지출 금액(원)·대기 시간(분)·사진은 선택입니다. 식비·숙박비·응대·혼잡 체감은 각각 독립적으로 선택하며, 이용하지 않은 항목을 평가할 필요가 없습니다. 사진은 기존 사진 저장소에서 JPG·PNG 5MB 이하로 검증·재인코딩합니다.

등록 직후 `PENDING` 상태로 저장되고, 작성자와 관리자만 볼 수 있습니다. `/admin/visit-reviews`에서 관리자만 승인·반려할 수 있습니다. 반려 이유는 필수이고 작성자의 **내 후기·검토 상태**에서 표시됩니다. 공개 후기는 익명으로 표시하고 회원 아이디나 관리자 메모를 공개하지 않습니다.

승인된 글을 작성자가 수정하면 다시 `PENDING`으로 변경되어 공개·집계에서 빠집니다. 수정본을 다시 승인해야 재공개됩니다. 작성자 또는 관리자는 후기를 삭제할 수 있습니다. 수정·삭제·검토 요청은 현재 `version`을 전송해야 하며 오래된 버전은 409로 거절합니다. JPA 낙관적 잠금도 적용해 동시 수정과 승인으로 미검토 내용이 공개되지 않도록 합니다.

## 종합 화면

`GET /api/visit-reviews/summary?destination={slug}&year={작성연도}`는 승인된 직접 후기만 집계합니다. `year`를 생략하면 전체 연도입니다. 기존 외부 글의 작성 연도 필터에 맞춰 직접 후기 역시 **작성 연도** 기준으로 필터링하고 방문 날짜는 원문 카드에 따로 표시합니다.

홈의 **여행자 직접 방문 후기** 영역에서 외부 수집 자료와 구분하여 승인 글 수·칭찬 글 수·아쉬움 글 수 및 식비·숙박비·응대·혼잡 체감을 표시합니다. 한 글이 여러 만족·불만을 담아도 각 전체 칭찬·불만 수에는 한 번씩만 계산합니다. 미이용 항목은 관련 후기 수에 넣지 않고 중립 혼잡은 불만으로 바꾸지 않습니다. 실제 지출액은 주문 품목·수량이 다르므로 평균 가격으로 계산하지 않습니다. 자유 서술 전체를 특정 분야의 근거로 임의 분류하거나 LLM 분석 결과로 표시하지 않습니다.

## 저장·권한

새 `visit_review` 테이블은 기존 `spring.jpa.hibernate.ddl-auto=update` 설정으로 서버 시작 시 생성됩니다. 기존 커뮤니티 글을 방문 후기나 승인 상태로 자동 변환하지 않습니다. 사진은 커뮤니티 또는 승인된 방문 후기에 연결되어 있을 때만 공개하며, 검토 중·반려된 사진은 작성자와 관리자만 확인할 수 있습니다. 사진 삭제 시 두 종류의 게시글 참조를 모두 확인해 다른 글의 사진이 삭제되지 않도록 합니다.

API 목록:

| 경로 | 기능·권한 |
|---|---|
| `GET /api/visit-reviews` | 승인 목록·관광지·작성 연도·12건 페이지, 공개 |
| `GET /api/visit-reviews/{id}` | 승인 글은 공개, 비공개 글은 작성자·관리자 |
| `GET /api/visit-reviews/mine` | 본인 글과 검토 상태, 로그인 필수 |
| `POST /api/visit-reviews` | 등록, 로그인·CSRF 필수 |
| `PUT /api/visit-reviews/{id}` | 본인 수정·검토 재요청, CSRF·version 필수 |
| `DELETE /api/visit-reviews/{id}?version=...` | 본인·관리자 삭제, CSRF 필수 |
| `GET /api/admin/visit-reviews?status=PENDING` | 검토 목록, 관리자 필수 |
| `PATCH /api/admin/visit-reviews/{id}` | 승인·반려, 관리자·CSRF·version 필수 |
| `GET /api/visit-reviews/summary` | 관광지·작성 연도별 승인 집계, 공개 |

## 검증

`./mvnw test`의 방문 후기 통합 테스트에서 등록·승인·반려·재요청·삭제, 작성자·관리자 권한, CSRF, 오래된 버전 거부, 연도·관광지 분리, 사진 공개·소유권·공유 참조, 페이지 처리 및 공개·관리자 HTML 렌더링을 검증합니다. `node src/test/js/visit-reviews.test.cjs`는 작성·로그인·검토 화면을, `node src/test/js/visit-overview.test.cjs`는 홈의 독립 집계·기간 선택·늦게 도착한 응답 처리를 검증합니다.
