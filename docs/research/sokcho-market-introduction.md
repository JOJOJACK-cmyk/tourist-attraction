각 자료의 표현·사진을 복제하지 않고 사실을 요약해 직접 작성했다. 음식 선택 체크와 둘러보는 순서는 이 사이트의 편집 제안이며 관광기관 지정 코스가 아니다. 지도 링크는 검색 링크이며 도보 시간·거리나 동선을 보장하지 않는다. 상품을 모두 속초산으로 표현하지 않으며 원산지 확인 안내를 넣었다. 운영·요금 정보는 오래된 기사마다 달라 고정 수치로 옮기지 않았다. 영금정·갯배의 요금과 시간, 특정 가게 추천, 현재 판매 가격은 포함하지 않는다.
