# 로그인·회원가입 페이지

`/login`은 독립 계정 화면입니다. 로그인·회원가입 탭, 설정된 네이버·구글 로그인, 이미 로그인된 계정 확인·로그아웃을 제공합니다. `?mode=signup`으로 회원가입 탭을 바로 열 수 있습니다. 기존 비밀번호·세션·CSRF API를 재사용합니다. 회원가입 후 같은 아이디로 로그인할 수 있게 안내하고, 로그인 후 CSRF 토큰을 갱신한 뒤 원래 화면으로 이동합니다.

주요 페이지 상단에 비로그인 사용자는 **로그인·회원가입**, 로그인 사용자는 **내 계정** 링크를 표시합니다. `?next=`에는 원래 페이지와 관광지·채팅방·게시판 선택값을 보존합니다. 반환 주소는 서버와 브라우저에서 내부 페이지 목록으로 검증하며 외부 주소·API 경로·로그인 반복 주소는 홈으로 대체합니다.

새 로그인 페이지의 소셜 버튼은 `/auth/social/{provider}?next=...`로 연결됩니다. 성공하면 해당 내부 화면으로 돌아가고 실패하면 선택값을 보존한 로그인 화면으로 돌아옵니다. 기존 커뮤니티의 `?board=question/free` 소셜 흐름도 유지합니다. 설정되지 않은 소셜 버튼은 숨기고 아이디 로그인 안내를 표시합니다. 클라이언트 키·비밀값을 화면에 노출하지 않습니다.

검증: `LoginPageIntegrationTest`, `SocialLoginIntegrationTest`에서 공개 페이지·메뉴·실제 세션 로그인·CSRF 갱신·반환 주소·소셜 복귀를 검증합니다. `node src/test/js/login-page.test.cjs`는 탭 전환·비밀번호 확인·가입 후 로그인·계정 상태·로그아웃·재연결을 검증합니다.

닉네임은 회원가입 시 선택 입력하거나 로그인 후 **내 계정 → 내 프로필**에서 설정·변경합니다. 일반 회원과 네이버·구글 회원 모두 사용할 수 있습니다. 자세한 데이터·표시 기준은 `docs/member-nicknames.md`를 참고합니다.
