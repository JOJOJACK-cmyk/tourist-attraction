# 속초 후기 요약 30건에 시스템 프롬프트 적용

생성일: 2026-10-02. 작성: assistant. 유형: `assistant_prompt_pilot`.

## 입력과 결과

입력은 `sokcho-review-pilot.json`의 출처별 검토 요약입니다. 새 원문을 수집하거나 Ollama를 호출하지 않았습니다. 프롬프트의 `source_id`는 `pilot-1`부터 `pilot-30`까지이며 `sourceId`로 기존 출처 번호에 연결합니다. 입력 검토 자료의 확인일은 2026-09-30입니다.

출처별로 `review-extraction-schema.json`의 `experiences`, `limitations` 형식을 유지합니다. 30개 분석에 총 57개 경험이 있고, 한 분석의 항목 수는 스키마 제한 20개 이내입니다. 13번·16번은 방문 선택과 관련된 구체적인 조건 없이 감상·추천만 있어 빈 배열을 사용했습니다. 본문 대신 요약을 사용한 한계로 직접 경험 여부는 전부 `unclear`, 방문일은 `null`입니다. 날짜는 기존 작성일을 복사했고, 근거 `support`는 입력 요약입니다. 실제 이용한 대안을 확인하지 못해 `alternative`는 전부 `null`입니다. 프롬프트와 입력 파일의 SHA-256을 데이터에 기록합니다.

## 판단 범위

- 가격 만족은 술빵·누룽지 오징어순대·회 세트의 크기·구성·가격을 함께 언급한 내용만 기록합니다. 맛있다는 감상만으로 가성비를 평가하지 않습니다.
- 술빵의 따뜻한 상태, 식은 상태, 재가열 경험을 함께 보존합니다. 식은 뒤 아쉬웠다는 의견을 전체 포장 음식의 문제로 확대하지 않습니다.
- 대기는 술빵, 닭강정, 누룽지 오징어순대, 일반 오징어순대 등 대상을 구분합니다. 대기 관찰은 중립, 빠른 수령과 부담은 별도 경험입니다. 구매에 이르지 못했다는 반응을 직접 대기 완료로 간주하지 않습니다.
- 주차는 2025년 6번 입력의 평일 주차 여유·가게별 주차권 차이뿐입니다. 숙박·교통·입장·대여·편의시설 근거는 만들지 않습니다.
- 젓갈 구매·택배 재주문은 쇼핑 경험으로 구분하며, 택배 서비스가 방문 당시 서비스였다고 표시하지 않습니다.
- 26번 조리 상태는 개인 주장 1건, 29번은 리뷰 이벤트 소개에 따른 유인 가능성, 혼합 여행기의 시장 밖 식당 경험은 제외했다는 내용을 출처별 `limitations`에 기록합니다. 관련 원문을 펼칠 때 이 메모를 함께 표시합니다.

## 화면 집계

작성 연도로 선택한 원래 출처 ID에 맞춰 분석 결과를 선택합니다. 경험은 **영역·장소·상품·주제·감정**별로 묶고 한 그룹에서 같은 출처는 한 번만 셉니다. 서로 다른 가게·상품의 경험을 한 결론으로 합치지 않습니다. 같은 후기에서 만족과 불만이 동시에 나오면 두 쪽을 모두 표시합니다. 관련 요약 건수는 실제 관광객 수·발생 확률이 아닙니다.

요약만으로 직접 경험을 재확인하지 못했으므로 `표본에서 반복된 경험`이라는 직접 경험 3건 이상 판정은 적용하지 않습니다. 화면은 `관련 요약 N건`, `만족 단서`, `주의 단서`로 표시합니다. 원래 수동 주제 검토는 별도 펼침 영역에 유지합니다.

공개 화면의 질문은 선택한 경험에서 생성하고 그 질문에 사용한 출처만 근거로 연결합니다. 2026년에는 주차 질문이 나오지 않으며, 2025년·전체 선택에서만 나타납니다. 실제 현재 대기시간·현재 가격을 안내하지 않습니다.

Ollama 실제 응답을 자동 보관·공개하는 운영 기능은 이번 작업에서 추가하지 않았습니다. 지금은 같은 경험 스키마로 저장한 예시를 공개하는 단계입니다.
